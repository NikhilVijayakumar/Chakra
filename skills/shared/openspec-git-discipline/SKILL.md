# OpenSpec Git discipline

Inspect the current branch, working tree, repository instructions and applicable protection and review rules before branch, commit, merge or archive operations. Preserve unrelated changes. Do not assume a develop branch, a particular branch naming convention, or permission to commit or merge. Include the change ID in handoffs and relevant review materials where practical. Archive only when implementation, applicable verification and integration have actually occurred; report outstanding gates and follow the user's instructions.
